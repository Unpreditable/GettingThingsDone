## 0.3.0

#### 새 기능
- 해낸 일 보기: 리본의 🏆를 클릭하면 오늘, 어제, 이번 주, 지난주에 완료한 작업을 10주 그래프와 함께 볼 수 있습니다.
- 작업의 마감일과 예정일을 우클릭 메뉴에서 바꿀 수 있습니다.

- 아직 시작할 수 없거나 다른 작업을 기다리는 작업은 흐리게 표시됩니다.
- Tasks의 Dataview 형식 필드를 읽습니다.

## 0.2.6

#### 새 기능
- **전역 작업 필터**: Tasks 플러그인처럼, 지정한 텍스트 중 하나를 포함한 체크박스만 작업으로 셉니다. 하위 작업 포함, 패널에서 필터 텍스트 숨기기 옵션이 있습니다.
- **진행 중과 취소**: 편집기 명령과 우클릭 메뉴 항목으로 작업을 진행 중 또는 취소로 표시합니다. 다시 실행하면 열린 상태로 돌아갑니다.

#### 수정
- Windows 줄 바꿈을 쓰는 노트의 작업이 패널에 나타나지 않던 문제를 수정했습니다.
- Tasks 편집 대화 상자에서 취소하면 작업 줄이 지워지던 문제를 수정했습니다.
- 검토 필요에서 방금 체크한 작업이 사라지고, 숨긴 작업이 다시 나타나던 문제를 수정했습니다.
- 일치하는 작업이 모두 숨겨져도 검색 시 버킷이 화면에 남던 문제를 수정했습니다.

## 0.2.5

#### 새 기능
- **패널에서 링크 열기**: 작업 안의 링크를 클릭하면 열립니다.

#### 수정

## 0.2.4

#### 새 기능
- **작업 편집**: 우클릭 메뉴에서 Tasks 플러그인의 편집 대화 상자로 작업을 엽니다.
- **작업으로 이동**: 작업을 열면 그 줄이 가운데로 오고, 커서가 놓이며, 잠시 강조 표시됩니다.
- 설정 → 모양에서 기본 메뉴를 끄면 우클릭 메뉴의 모든 항목에 아이콘이 표시됩니다.

## 0.2.3

#### 새 기능
- **더 많은 체크박스 상태**: 진행 중 `[/]`, 전달됨 `[>]`, 예정됨 `[<]`은 열린 작업으로 표시되고, 취소 `[-]`는 완료로 셉니다.
- 패널에 이 상태들에 대한 테마 고유의 아이콘이 표시됩니다.

## 0.2.2

#### 새 기능
- **주 시작 요일**: 설정에서 고르면 이번 주와 다음 주가 그에 맞춰집니다.
- **볼트 전체 검사 제외 항목**: 선택한 폴더와 파일을 건너뜁니다. 폴더 목록과 파일 목록이 하나로 합쳐졌습니다.

#### 수정
- Obsidian 1.13 이상에서 사용자 지정 설정 섹션이 잘못 표시되던 문제를 수정했습니다. "Getting Things Done" 섹션은 이제 "일반"입니다.
- 상위 작업이 화면에 없는 하위 작업에 ↖︎ 배지가 없던 문제를 수정했습니다. 이제 툴팁에 상위 작업이 표시됩니다.

## 0.2.1

#### 새 기능
- **작업 날짜**: 마감일, 예정일, 둘 중 이른 날짜, 또는 날짜 없이 작업을 배치합니다.
- **날짜순 버킷**: 버킷 안의 작업이 날짜순으로 정렬되고, 날짜 없는 작업은 맨 뒤에 옵니다. 드래그 앤 드롭으로 정리한 버킷은 그 순서를 유지합니다.
- **고정과 고정 해제**: 작업을 버킷에 고정하거나, 고정을 해제해 다시 날짜를 따르게 합니다.
- "기한 지남"과 "잘못 분류됨" 표시가 분리되었고, 팝오버에서 설명합니다.
- **전체 (나머지 모두) 규칙**: 위 버킷들이 가져가지 않은 날짜 있는 작업을 모두 가져옵니다. 기본적으로 "언젠가 / 어쩌면"에 설정되어 있습니다.
- 아이콘이 Obsidian과 테마를 따릅니다.

#### 수정
- Obsidian 시작 후 추가한 노트가 다시 시작할 때까지 나타나지 않던 문제를 수정했습니다.

## 0.2.0

#### 새 기능
- **유지되는 작업 순서**: 드래그로 정한 순서가 파일 편집, 이름 변경, 폴더 이동, 재시작 후에도 유지됩니다.
- **Tasks 플러그인을 통한 완료**: 반복 작업은 다음 회차가 만들어지고, ✅ 날짜는 Tasks의 규칙을 따릅니다.
- 완료한 작업은 다시 불러올 때까지 패널에 남습니다.
- **Tasks 플러그인 필드**: 우선순위, 반복, 날짜, 완료 시 동작이 배지와 팝오버에 표시되고, 어떤 것을 보일지 설정할 수 있습니다.
- **"기한 지남"과 "잘못 분류됨" 표시**, 그리고 팝오버의 마감일 줄.
- 리본 아이콘으로 패널을 엽니다.

#### 수정
- 다른 버킷으로 끌어온 작업이 엉뚱한 위치에 놓이고, 하위 작업이 상위 작업에서 떨어지던 문제를 수정했습니다.
- 다시 불러오거나 업데이트할 때 두 번째 패널이 열리고, 버킷이 자정에 넘어가지 않던 문제를 수정했습니다.
- Tasks 플러그인 메타데이터가 작업 텍스트에 섞이고, 드래그 중 툴팁이 뜨던 문제를 수정했습니다.
- 피드백용 GitHub 링크를 열기 전에 확인합니다.
