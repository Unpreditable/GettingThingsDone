## 0.3.0

#### 新機能
- やり遂げたことを見る：リボンの 🏆 をクリックすると、今日・昨日・今週・先週に完了したタスクが10週間のグラフとともに表示されます。
- タスクの右クリックメニューから期日と予定日を変更できます。
- 「進行中」「キャンセル」のコマンドに加えて **タスクの完了を切り替え** コマンドを追加。
- まだ開始できないタスクや、ほかのタスクを待っているタスクは薄く表示されます。
- Tasks の Dataview 形式のフィールドを読み取ります。

## 0.2.7

- 変更はありません。Obsidian の公開チェックの問題を回避するため 0.2.6 を再リリースしました。

## 0.2.6

#### 新機能
- **グローバルタスクフィルター**：指定したテキストのいずれかを含むチェックボックスだけをタスクとして扱います（Tasks プラグインと同様）。サブタスクを含めるオプションと、パネルでフィルターのテキストを隠すオプションがあります。
- **進行中とキャンセル**：エディターのコマンドと右クリックメニューの項目で、タスクを進行中またはキャンセルにできます。もう一度実行すると未完了に戻ります。

#### 修正
- Windows の改行コードを使うノートのタスクがパネルに表示されない問題を修正。
- Tasks の編集ダイアログで「キャンセル」するとタスクの行が消える問題を修正。
- レビュー待ちがチェックしたばかりのタスクを失い、非表示にしたタスクが戻ってくる問題を修正。
- 一致したタスクがすべて非表示でも、検索でバケットが画面に残る問題を修正。

## 0.2.5

#### 新機能
- **パネルからリンクを開く**：タスク内のリンクをクリックすると開きます。

#### 修正
- ウィキリンクの #見出し と URL の #フラグメント がパネルのタスクテキストから消える問題を修正。

## 0.2.4

#### 新機能
- **タスクを編集**：右クリックメニューから Tasks プラグインの編集ダイアログでタスクを開きます。
- **タスクへ移動**：タスクを開くと、その行が中央に表示され、カーソルが置かれ、一瞬ハイライトされます。
- 設定 → 外観 でネイティブメニューがオフのとき、右クリックメニューのすべての項目にアイコンが付きます。

## 0.2.3

#### 新機能
- **チェックボックスの状態を追加**：進行中 `[/]`、転送 `[>]`、予定 `[<]` は未完了のタスクとして表示され、キャンセル `[-]` は完了として扱われます。
- パネルはこれらの状態にテーマ独自のアイコンを表示します。

## 0.2.2

#### 新機能
- **週の開始日**：設定で選ぶと、「今週」と「来週」がそれに従います。
- **保管庫全体のスキャンからの除外**：選んだフォルダーとファイルをスキップします。フォルダーとファイルのリストは1つにまとめられました。

#### 修正
- Obsidian 1.13 以降で独自の設定セクションの表示が崩れる問題を修正。「Getting Things Done」セクションは「一般」になりました。
- 親タスクが画面にないサブタスクに ↖︎ バッジが付かない問題を修正。ツールチップに親タスクが表示されるようになりました。

## 0.2.1

#### 新機能
- **タスクの日付**：期日、予定日、そのうち早いほう、またはどちらも使わずにタスクを振り分けます。
- **日付順のバケット**：バケット内のタスクは日付順に並び、日付のないものは最後になります。ドラッグ＆ドロップで並べたバケットはその順序を保ちます。
- **固定と固定解除**：タスクをバケットに固定するか、固定を解除して再び日付に従わせます。
- 「期限切れ」と「振り分け違い」の別々のマーク（ポップオーバーで説明）。
- **すべて（残り全部）ルール**：上のバケットが取らなかった日付付きのタスクをすべて受け取ります。既定では「いつか / もしかしたら」に設定されています。
- アイコンは Obsidian とテーマに合わせて表示されます。

#### 修正
- Obsidian の起動後に追加したノートが再起動するまで表示されない問題を修正。

## 0.2.0

#### 新機能
- **保たれる並び順**：ドラッグで決めた順序が、ファイルの編集、名前の変更、フォルダーの移動、再起動の後も残ります。
- **Tasks プラグイン経由での完了**：繰り返しタスクは次の回が作られ、✅ の日付は Tasks のルールに従います。
- 完了したタスクは再読み込みするまでパネルに残ります。
- **Tasks プラグインのフィールド**：優先度、繰り返し、日付、完了時のアクションがバッジとポップオーバーに表示され、どれを表示するか設定できます。
- **「期限切れ」と「振り分け違い」のマーク**と、ポップオーバーの期日の行。
- リボンのアイコンでパネルを開けます。

#### 修正
- ほかのバケットへドラッグしたタスクが違う位置に入り、サブタスクが親から離れる問題を修正。
- 再読み込みや更新で2つ目のパネルが開き、バケットが深夜0時に切り替わらない問題を修正。
- Tasks プラグインのメタデータがタスクテキストに混ざり、ドラッグ中にツールチップが出る問題を修正。
- フィードバック用の GitHub リンクを開く前に確認するようになりました。
